# 🏨 Hotel Management System (Projeto Acadêmico)

Este é um sistema de gerenciamento de hotel desenvolvido em C# com Windows Forms. Ele permite o gerenciamento de reservas, quartos e informações de hóspedes de forma eficiente.

## 🚀 Tecnologias Utilizadas

- **Linguagem:** C#
- **Framework:** .NET Framework
- **Interface Gráfica:** Windows Forms
- **Banco de Dados:** SQL Server

## 📦 Funcionalidades

- Login seguro para usuários e administradores.
- Painel interativo com visão geral das operações.
- Gerenciamento de reservas, quartos e hóspedes.
- Relatórios detalhados de ocupação e receitas.
